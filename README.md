# Automated Business Operations & Performance Analytics

## Overview

I am building an end to end business analytics solution that automates recurring reporting tasks and combines SQL, Power BI, Power Query, Power Automate, Excel, Python, and AI.

The project focuses on transaction, customer, product, location, cost, and target data. I use Python for incoming file validation and preprocessing, SQL for data modelling and analysis, Power BI for reporting, Power Automate for workflow automation, and AI for management summaries based on verified KPI results.
